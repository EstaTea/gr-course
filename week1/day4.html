4.2 GRDC（Group Reporting Data Collection）

GRDC 是 SAP BTP 上的独立应用，专门解决非 S/4HANA 系统的数据采集问题（写入 ACDOCU 合并表）。

GRDC 功能说明
Data Mapping（数据映射）自动化的数据转换和加载：SAP/非SAP系统 → 映射规则 → ACDOCU；支持 Traceability Log 追溯
GRDC Forms（表单）子公司通过 Web 表单手工填报财务/非财务数据；支持注释和附件
数据中心3个可用数据中心：欧洲、欧洲（EU-only）、加拿大
租户数量标准提供3个租户：开发/测试/生产

4.3 GRDC 2402 增强功能

  • Traceability Log 增强：支持为定时任务和 Push API 自动生成追溯日志；可强制每次运行都生成日志
  • 云存储支持：追溯日志和 CSV 输出文件可直接保存到 Google Drive / OneDrive / SharePoint
  • 日志列增强：导入日志和追溯日志新增列，与 Task Logs 对齐

📝 知识测验 — Day 4

Q1. 华照集团的沪乐公司使用用友U8系统，应该用哪种方式将数据采集到 Group Reporting？
✅ 实时直接集成只适用于同一个 S/4HANA 实例中的法人。沪乐使用用友U8（非SAP），应使用文件上载（Excel格式）或 GRDC Data Mapping 自动化映射。在佛照项目中，沪乐计划在二期迁移到 S/4HANA PS模块，迁移前使用文件上载方式。
Q2. GRDC 是部署在哪个平台上的应用？
✅ GRDC 是 BTP 应用，始终部署在 SAP 公有云（与 Group Reporting 实例是否在私有云无关）。即使 Group Reporting 部署在 Private Cloud Edition（PCE），GRDC 仍在 BTP 公有云，通过安全连接与 PCE 实例通信。目前有3个数据中心可选：欧洲、欧洲EU-only、加拿大。
Q3. GRDC Traceability Log 的作用是什么？
✅ Traceability Log（追溯日志）让你能够追踪每一笔合并数据的来源：源系统原始值 → 映射规则如何转换 → 最终写入 ACDOCU 的值。这对审计和数据质量分析非常重要。2402增强后，定时任务和 Push API 也能生成追溯日志，并可保存到云存储（Google Drive/OneDrive）。
