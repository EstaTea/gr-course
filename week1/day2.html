2.4 时间相关属性

合并单元主数据支持时间相关属性（SAP Feature Deck 2402）：

  • 本位币：泰国FZ40用泰铢THB，德国FZ33用欧元EUR
  • 货币折算方法：每个合并单元可独立配置
  • 数据采集选择：决定如何采集该单元数据（S/4直连 vs GRDC）

📝 知识测验 — Day 2

Q1. Consolidation Unit 和 Company Code 是什么关系？
✅ Consolidation Unit（合并单元）映射到 S/4HANA 的 Company Code，通常一对一对应。Cons Unit 是 GR 层的主数据，Company Code 是 FICO 层的主数据，通过映射关系连接。
Q2. 华照沪乐外部股东持有30%，合并 B/S 中需要处理什么？
✅ 控制原则（IFRS 10）：华照持股70%即控制沪乐，必须全额并入合并报表，但权益中须单独列示NCI（30%对应净资产），P&L中区分归属母公司和少数股东的利润。SAP GR 通过 COI 任务自动处理。
Q3. 2402版本对 Activity-based COI（ABCOI）有什么限制？
✅ SAP Feature Deck 2402 明确：ABCOI 从2402起不再对新公有云客户开放，已在使用的现有客户可继续。新项目（含佛照）应使用 Rule-based COI（Task 2100系列）。
