5.2 Release Universal Journal（发布通用日记账）

Release UJ 是数据监控器中最核心的任务——将 ACDOCA（会计核算）数据发布到 ACDOCU（集团合并）。

5.3 货币折算方法

华照集团有泰国（THB）和德国（EUR）两个境外法人，货币折算是关键步骤。SAP 预置方法（来源：Feature Deck Slide 54）：

方法代码名称适用场景
Y0901Standard YTD（标准年累计）最常用，按年累计金额折算
Y0902Keep GC from S4 / B/S retranslate @ closing保留 S4 中的集团货币值，期末重新折算 B/S
S0901Period of acquisition YTD并购期间年累计
S0903Standard Periodic（标准分期）按期间分别折算
华照泰国FZ40（THB）折算策略：B/S 科目用期末汇率折算（现行汇率法）；P&L 科目用平均汇率折算；汇兑差异记入权益项目（OCI）。德国FZ33（EUR）同样适用，需在合并单元主数据中为每个法人单独配置折算方法。

📝 知识测验 — Day 5

Q1. 数据监控器（Data Monitor）主要管理什么层面的合并任务？
✅ Data Monitor（数据监控器）负责单个合并单元（法人）的数据准备流程。Consolidation Monitor（合并监视器）才负责集团层面的消除任务（IC消除、投资消除等）。两者分工明确：Data Monitor 是"各家公司准备好自己的数据"，Consolidation Monitor 是"集团层面做消除"。
Q2. 华照泰国 FZ40 使用泰铢（THB），在集团合并报表中需要转换为人民币（CNY）。B/S 科目应该用什么汇率折算？
✅ 按 IFRS/CAS 准则，现行汇率法下：B/S 科目（资产、负债、权益）用期末即期汇率折算；P&L 科目用业务发生时的即期汇率（实务中通常用平均汇率近似）；折算差额计入其他综合收益（OCI）。这是 SAP GR 的默认设置，通过配置货币折算方法（Y0901等）实现。
Q3. 2402 版本的 Release Universal Journal"Update 模式"有什么变化？
✅ 2402 Feature Deck 明确：Update 模式变为"几乎一键操作"——选择 Update 后弹出确认窗口，用户确认后系统立即在更新模式下执行，不再显示复杂的选择界面。所有高级选项（如子集选择）移到了新的"Start with Selection"模式中。
